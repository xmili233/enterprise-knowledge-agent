本章说明当前版本实际实现了什么，以及背后的主要技术取舍。

## 当前实现

| 部分 | 实现方式 |
| --- | --- |
| 查找过程 | `src/lib/research.ts` 预设九个场景，按关键词匹配；`src/lib/knowledge-adapter.ts` 把查找过程回放为 assistant-ui 的消息片段 |
| 会话 | assistant-ui 的 `useLocalRuntime` 管理消息流、发送、停止和滚动；引导演示依次发送三个预设问题，输入框不能修改；回答底部不提供复制或重新查找操作 |
| 过程展示 | RunActivity 按轮次折叠思考和工具调用；检索与证据工具通过 `makeAssistantToolUI` 注册界面 |
| 回答与引用 | MarkdownText 渲染正文，行内引用预览原文；DocumentReference 在回答下方汇总引用文件 |
| 原文面板 | shadcn/ui 抽屉，句子级高亮，可在多处引用之间跳转 |
| 知识库浏览 | 访达式文件夹网格，文件和文件夹在同一目录中统一搜索 |
| 资料 | `src/data/knowledge.ts`：6 个文件夹、11 份虚构文件 |
| 网络 | 不发送任何网络请求，不连接模型 |

| 数据 | 保存方式 |
| --- | --- |
| 会话标题、消息、分支和引用元数据 | 浏览器 localStorage |
| 查找中的进度 | 页面内存 |

数据不跨设备同步，当前也不提供历史浏览和删除界面；返回首页开始新对话时，旧记录保留在本地。

## 前端与服务的分工

assistant-ui 管理前端会话和消息流，不负责解析文档、检索资料或判断证据。接入真实服务时，只需替换适配器中的本地回放，界面按以下契约继续工作：

| 消息片段 | 内容 |
| --- | --- |
| `reasoning` | 每轮的思考文本 |
| `tool-call`：`search_knowledge` | 参数为查询词和范围；结果为命中文件，包括标题、版本、更新日期和位置 |
| `tool-call`：`gather_evidence` | 参数为本轮子问题；结果为每段的分数、摘要、是否采用，以及阈值和统计 |
| `text` | 带引用编号的回答正文 |
| 消息元数据 | 引用登记表（编号、段落、摘录、版本、页码）、查找轮次和结束状态 |

服务端负责生成证据登记表，前端按编号解析引用，不接受模型自行编写的来源链接。

## 主要取舍

| 选择 | 收益 | 代价 |
| --- | --- | --- |
| 纯前端回放，不接模型 | 无需 Key 和后端，打开即可体验完整流程 | 不展示真实模型的判断能力，任意提问不保证能被理解 |
| 引导演示固定三个问题 | 每一步都能看到找到、打分和引用的完整过程 | 访客不能自由提问；拒答场景只能在讲解中查看 |
| 采用 assistant-ui | 消息流、停止和滚动等交互可靠；接入真实服务时界面不用重写 | 数据需要按它的消息片段模型组织 |
| 准确优先的多轮查找 | 条件更完整，拒答也有依据 | 回答更慢、成本更高，需要分级和上限 |
| 句子级引用 | 结论与原文可以逐句对照 | 依赖原样抄录，需要校验和降级 |
| 只借鉴四个项目的思路 | 演示轻量，设计可以按环节组合 | 真实落地仍需选择底座，并补齐后端 |

## 演进顺序

如果接入真实服务，按以下顺序推进，每一步都可以单独验证：

1. **检索与证据服务**：接入入库、混合检索和 `gather_evidence` 打分，适配器改为流式调用；同时建立评测集，记录查找过程。
2. **引用校验与降级**：每次回答执行逐字校验，并提供段落级兜底。
3. **权限与版本**：接入企业登录和权限同步，检索按权限与现行版本过滤。
4. **分级与上限**：按问题类型选择快速路径或完整循环，设定轮次和时长上限。

## 验证

自动化测试覆盖查找过程与资料的对应、引文原样出自原文、只引用通过阈值的证据、拒答场景、适配器的片段顺序与停止，以及本地会话存储。`npm run build` 检查 TypeScript 并生成生产资源。浏览器中验证桌面和手机下的首屏布局、切屏、文件夹进出、文件搜索、问答、停止、引用定位和设计讲解。

## 界面规范

布局依据用户确认的参考图：全宽白色画布、居中提问框、首屏底部的向下浏览入口；空白首页左上角是书本图标和产品名称，进入聊天后隐藏；不使用侧栏。视觉决定记录在项目根目录的 `DESIGN.md`；颜色、主要尺寸和圆角统一在 `src/design-tokens.css`；`AGENTS.md` 要求修改界面前先阅读设计规范。界面只展示可用的操作，不放会员、语音或附件这类占位按钮。
